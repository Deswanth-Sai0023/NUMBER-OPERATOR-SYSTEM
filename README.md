# Number Operating System

A simple and interactive **Number Operating System** built using **HTML, CSS, and JavaScript**. This project allows users to perform different operations on numbers through a clean and user-friendly interface.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Number input handling
- ⚠️ Validation for invalid inputs
- 📱 Responsive user interface
- 🎨 Clean and simple design
- ⚡ Instant results using JavaScript

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Logic and calculations

## 📂 Project Structure

Number-Operating-System/

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html` in your browser.
4. Enter the required numbers.
5. Select the operation you want to perform.
6. View the result instantly.
